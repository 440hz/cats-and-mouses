## Решения пользователя (зафиксированы)

1. **Кнопки** — сейчас простые (программная отрисовка), но структура позволяет позже подменить на сгенерированный арт (текстура-фон). Генерация арта через SpriteCook доступна (токены есть) — только с подтверждением по AGENTS.md.
2. **Game Over / Win — классика**: только по кнопке, без авто-перехода через 2 сек.
3. **Жизни в HUD — 3 сердечка**: 1 активное (полное) + 2 пустых. Это placeholder под Этап 6 (механика жизней остаётся в Этапе 6). Спрайт сердечка сгенерировать (подтверждение по AGENTS.md).
4. **«Продолжить» в меню — да**: прогресс в `Gdx.app.Preferences`. Хранение: при победе на карте N → `lastLevel = N+1`, `lastScore` = счёт со старта карты 1; «Продолжить» стартует с сохранённой карты и этого счёта.
5. **ESC → «Выйти?»** (везде): первый ESC открывает диалог с кнопками «Выйти»/«Отмена»; «Выйти» → `Gdx.app.exit()`; повторный ESC = «Отмена» → возврат откуда вызвали.
6. **Кнопка «Выход» в меню**: только Desktop (на Android скрывать — системная «назад»).

## Ход работ

1. **Preferences + навигация** (`MainGame.kt`): ключи `bestScore`, `lastLevel`, `lastScore`, `hasProgress`. Создание экранов, передача Preferences. Дебаг/AI-режим (флаги из `Lwjgl3Launcher`) идёт сразу в GameScreen, меню пропускается — MCP/AI не ломается.
2. **UI-примитивы** (`UiElements.kt`) + **tap vs swipe** (`InputHandler.kt`). Кнопка рисуется текстурой-фоном + текстом; сейчас фон можно рисовать программно (заглушка), но поле `texture` должно быть готово к подмене сгенерированным спрайтом.
3. **HUD-плашка** (`GameScreen.kt`): полупрозрачная панель сверху на всю ширину. Слева `Score` + `Рекорд`; центр `Сыр: n/всего` + `Карта N/5`; справа 3 сердечка (1 полное + 2 пустых). Легенда котов — вниз-слева, версия — вниз-справа. `getLives()` для отрисовки сердечек (актуально 1). Шрифты `generateFont`: 20 HUD / 32 оверлеи / 48 титул.
4. **Главное меню** (`MainMenuScreen.kt`): фон-тайлы активной темы, титул «CATS AND MOUSES», рекорд, кнопки. «Играть» → старт с карты 1. «Продолжить» → старт с `lastLevel`/`lastScore` (видна только при `hasProgress`). «Выход» — Desktop только. Enter = активация фокусной кнопки.
5. **Пауза** (оверлей GameScreen): затемнение + «ПАУЗА», кнопки «Продолжить» / «Заново» (текущая карта) / «В меню». Space — как раньше.
6. **Game Over** (без авто-таймера): затемнение, «GAME OVER» + «Поймал <имя кота>» + счёт + рекорд; кнопки «Заново» (с карты №1, актуальная логика рестарта) и «В меню».
7. **Win** (без авто-таймера): «УРОВЕНЬ ПРОЙДЕН!» + счёт + рекорд; кнопка «Следующая карта» (на финальной — «В меню»). При победе обновить Preferences: `bestScore` (max), `lastLevel = N+1`, `lastScore`, `hasProgress = true`.
8. **Диалог «Выйти?»** по ESC во всех состояниях (игра/пауза/меню): кнопки «Выйти»/«Отмена», второй ESC = отмена. Убрать мгновенный exit.
9. **Генерация ассетов через SpriteCook** — 2 процедуры, каждая с обязательным подтверждением (AGENTS.md, Шаги 1–4: баланс → список моделей → рекомендация → «Какую модель использовать?»):
   - сердечко активное + пустое (16-bit пиксель-арт, стиль сыра/мыши) → `assets/sprites/heart_full.png`, `heart_empty.png` + `raw/`;
   - фон кнопки (и при желании фон плашки/диалога) → `assets/ui/button.png` + `raw/`.
   После генерации: скачать RAW, сохранить в `raw/`, обновить `asset-manifest.json` и `GAME.md`.
