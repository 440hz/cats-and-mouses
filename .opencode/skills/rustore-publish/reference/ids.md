# Справочник: категории и поисковые теги RuStore

Источник: официальная документация RuStore (списки категорий и поисковых тегов API).
Файл нужен для `store/rustore/version.json` (`categories`, `seoTagIds`) и для заполнения карточки вручную.

## Возрастные категории (`ageLegal`)

`0+`, `6+`, `12+`, `16+`, `18+`.

## Тип версии (`appType`)

`GAMES` — игры, `MAIN` — неигровые приложения. Категории и теги должны соответствовать типу.

## Выбор для CATS AND MOUSES

- `appType`: `GAMES`
- `categories`: `arcade` (основная) + `casual` (дополнительная)
- `ageLegal`: `0+`
- `seoTagIds`: `[51, 52, 58, 61, 21]` — Однопользовательская игра, Офлайн, Пиксельная графика, Поиск выхода, Животные
