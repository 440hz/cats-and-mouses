# Git workflow (CATS AND MOUSES)

По просьбе «закоммить и пушнуть» выполняй строго по порядку:

1. Подними **patch-версию** в `android/build.gradle.kts` (`versionName`), например 1.0.0 → 1.0.1.
2. Добавь запись в `CHANGELOG.md`: новая секция версии по формату Keep a Changelog (тип изменения и краткое описание).
3. Создай ветку `1.0.1/<тип>/<суть>` — `<тип>`: `feature` | `docs` | `bugfix`; `<суть>` — краткое имя работы латиницей через дефис.
4. Закоммить изменения (сообщение краткое, по-русски), включая `android/build.gradle.kts` и `CHANGELOG.md`.
5. Запушь ветку: `git push -u origin <ветка>`.
6. Переключись на `master` (`git checkout master`) и смержи ветку.

## Важно

- Номер версии в имени ветки — всегда новая версия после поднятия patch.
- Не понижай версии зависимостей, не трогай `local.properties` и `opencode.json`.
- Перед коммитом проверяй статус и дифф (`git status`, `git diff`) — стейдж только нужные файлы.
