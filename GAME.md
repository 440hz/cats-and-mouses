# CATS AND MOUSES — описание проекта

## Что это за игра

2D-игра в стиле **Pac-Man** с инверсией ролей. Игрок управляет **мышью**, а **четыре кота** охотятся за ней. Цель — собрать весь сыр на лабиринте, не попавшись котам.

## Финишная версия (видение)

Зафиксированное видение конечной игры (детали этапов — в разделе «Следующие шаги»).

### Цель
Публикация в **RuStore** со всем необходимым: подпись APK/AAB (генерация keystore), иконка, скриншоты, описание, категория, политика конфиденциальности, стабильный билд без крашей.

### Персонажи
- **4 кота** (как 4 призрака у Пакмана), у каждого своя стратегия/имя/цвет (сейчас 3: Барсик-Chaser, Матроскин-Patrol, Леопольд-Random; добавить 4-го).

### Карты и прогрессия
- **Много карт под номерами**: 1 → 2 → … → финальная; после прохождения — переход к следующей.
- **Финальная карта без стен** — открытое поле, все 4 кота максимально агрессивны (все преследуют).
- **При поимке без жизней — рестарт с карты №1** (прогресс карт сбрасывается).
- **Рекорд сохраняется в `Preferences`** и переживает выход из игры.
- **Безопасные клетки-убежища**: по ним ходит только мышь, коты не заходят. Стартовая клетка защищена по **гибриду**: защита истекает через несколько секунд стояния И исчезает навсегда после выхода (детали додумаем при реализации).

### Сыр (пеллеты)
- **Ручная расстановка**: клетки в `maze.txt` нумеруются `1 2 3` — столько сыра, сколько цифр.
- **Если ручной расстановки нет — автогенерация** в случайных достижимых клетках (как сейчас).
- Собрал весь сыр → карта пройдена.

### Жизни
- **Сердечки на клетках** добавляют жизнь.
- При поимке с жизнью: жизнь теряется, мышь **телепортируется в клетку максимально далеко от котов**.
- Без жизней: **рестарт с карты №1**.

### HUD
- **Верхняя плашка**: статистика (счёт, сыр на карте, жизни), рекорд, версия игры.

### Оформление — темы (скины локаций)
- Наборы: трава/кусты (текущая), замок/каменные стены, песок/пальмы и т.д. Каждая тема — свой фон, стены, декор.
- Плашка/стиль котов и мыши делаются под каждую тему.

### Опционально (вне RuStore)
- **Отдельное Desktop-приложение — редактор карт** (визуальная рисовка `maze.txt`), после релиза.

### Кандидаты на фишки (раскидаем при планировании этапов)
1. Режим испуга котов (волшебное сыро: коты боятся / мышь неуязвима несколько секунд).
2. Туннель-переход через край карты.
3. Бонусный предмет в центре (очки / сердечко).
4. Ускорение котов с каждой картой.
5. Комбо-мультипликатор за серию сыра.
6. Интермиссии-титры между картами.
7. Таблица рекордов (топ-5, локально).
8. Достижения (локальные).
9. Настройки: звук / музыка / вибрация / чувствительность свайпов.
10. Пауза.
11. Звуковой / вибрационный индикатор близости кота.
12. Секретная комната / бонус-сыро.

## Параметры игрового мира

- **Экран**: 1280×720 (landscape), FitViewport
- **Карта**: 28 колонок × 16 строк
- **Размер клетки**: 40×40 пикселей (лабиринт 1120×640, центрируется по экрану)
- **Символы карты**:
    - `#` — стена (непроходимая)
    - ` ` — пустой проход
    - Точки / пеллеты спавнятся логически в 3 случайных достижимых клетках (не отображаются символами на карте)

## Игровые объекты

### Мышь (игрок)
- **Скорость**: 150 пикселей/сек
- **Движение**: строго по сетке, поворот только в центре клетки
- **Управление Desktop**: WASD или стрелки
- **Управление Android**: пока не реализовано (планируется свайпы/тапы)
- **Внешний вид**: спрайт `mouse.png` (70×70 исходник, на экране 32×32), серый цвет с тёмным контуром, хвост виден; спрайт поворачивается по направлению движения

### Три кота (враги)
Все коты движутся по сетке со скоростью **120 пикселей/сек**, не проходят сквозь стены, не разворачиваются на 180° вне перекрёстков. Отличаются стратегией:

| Кот | Стратегия | Цвет | Поведение |
|-----|-----------|------|-----------|
| **Cat 1 — Chaser** | Преследователь | Красный `Color(1f, 0.125f, 0.125f, 1f)` | На каждом перекрёстке выбирает направление к мыши через BFS (кратчайший путь) |
| **Cat 2 — Patrol** | Патрульный | Синий `Color(0.125f, 0.375f, 1f, 1f)` | Ходит по периметру против часовой стрелки; если мышь в радиусе 5 клеток — переключается на преследование |
| **Cat 3 — Random** | Случайный | Фиолетовый `Color(0.625f, 0.125f, 0.94f, 1f)` | На перекрёстках идёт в случайную сторону, но с вероятностью 30% — в сторону мыши |

- **Внешний вид**: цветные круги радиусом 18 (временная заглушка), цвет зависит от стратегии
- **Стартовые позиции**: три угла лабиринта (верхний-левый, верхний-правый, нижний-левый)

## Правила игры

- **Старт мыши**: центр лабиринта (колонка 13–14, строка 8)
- **Сбор точек**: мышь наступает на клетку с пеллетой → точка исчезает, счёт += 100
- **Проигрыш**: кот коснулся мыши → надпись `GAME OVER` по центру, пауза 2 секунды, рестарт
- **Победа**: все точки собраны → надпись `YOU WIN`, пауза 2 секунды, рестарт
- **HUD**: счёт (`Score: N`) и оставшиеся точки (`Pellets: N`) в левом верхнем углу; легенда цветов котов (`Chaser`, `Patrol`, `Random`) в правом верхнем углу

## Карта лабиринта

Файл `assets/maze.txt` содержит 16 строк по 28 символов. Карта симметрична по горизонтали, имеет периметральный коридор и четыре угловые зоны для старта котов.

## Визуальные заглушки

Спрайты сейчас **частично заменены** на пиксель-арт:
- Фон — бесшовная трава (`assets/sprites/grass.png`, 200×200, непрозрачная), тайлы 40×40 по всей площади лабиринта
- Стены — кусты (`assets/sprites/bush.png`, 88×88, прозрачный фон, 16-bit пиксель-арт), тайлы 40×40
- Точки — белые кружки радиусом 4
- Мышь — спрайт `mouse.png` (70×70 исходник, 32×32 на экране), поворачивается по направлению движения
- Коты — цветные круги радиусом 18 (красный, синий, фиолетовый)
- Точки — белые кружки радиусом 4

**Планируется**: заменить оставшиеся заглушки (точки, коты) на анимационные спрайты через MCP-сервер SpriteCook.

## Известные проблемы

1. **Предупреждение Kotlin Gradle plugin** — «плагин загружен несколько раз в разных субпроектах». Безобидно, сборку не ломает. Стандартный фикс (перенос плагина в корень с `apply false`) несовместим с AGP 8.7 + Kotlin 1.9.24. **Решено оставить как есть.**
2. **Кэш Gradle иногда повреждается** — если появляется ошибка `Could not read workspace metadata`, нужно удалить `%USERPROFILE%\.gradle\caches\8.9\transforms` и пересобрать с `--no-daemon`.

## Правила для AI-агента

При работе над этим проектом:

1. **Не понижай версии** AGP, compileSdk, Kotlin без явной просьбы — текущая связка (AGP 8.7 + compileSdk 35 + Kotlin 1.9.24 + JDK 21) стабильна.
2. **Не трогай `local.properties`** — там путь к Android SDK, уникальный для машины.
3. **Не трогай `opencode.json`** без явной просьбы.
4. **Каждое изменение проверяй** через `.\gradlew build` перед тем, как считать задачу выполненной.
5. **Движение в игре строго по сетке** — не делай свободное перемещение.
6. **Коллизии считай по клеткам**, а не по пиксельным радиусам.
7. **При ошибках Gradle** сначала попробуй `--no-daemon`, потом чистить кэш.
8. **Не давай проекту расти бесконтрольно** — не добавляй библиотеки без необходимости.
9. **Все ресурсы освобождай в `dispose()`** — SpriteBatch, Texture, ShapeRenderer, BitmapFont.
10. **Стиль кода**: Kotlin, комментарии на русском, без лишних абстракций.
