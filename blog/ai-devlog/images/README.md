# Иллюстрации к девлогу

Картинки для [`../ARTICLE.md`](../ARTICLE.md). Схемы и графики рисуются локально
скриптом [`tools/make_devlog_illustrations.py`](../../../tools/make_devlog_illustrations.py)
(Pillow, единый стиль, `assets/fonts/ptsans.ttf`). Запуск:

```
python tools/make_devlog_illustrations.py
```
