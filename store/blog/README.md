# Блог RuStore — папка публикации

Материалы для статьи в [Блоге RuStore](https://www.rustore.ru/prostore) по формату
[«Публикация статьи в Блоге RuStore»](https://www.rustore.ru/help/developers/advertising-and-promotion/blog-publication)
(формат **«Обзор»**, категория **«Игры»**).

## Файлы

- [`BLOG-ARTICLE.md`](BLOG-ARTICLE.md) — текст статьи (черновик) + поля шапки.

## Что ещё нужно подготовить

1. **`article.docx`** — финальная верстка по требованиям RuStore:
   - шрифт **Arial**, название и подзаголовки стилем **«Заголовок 1»**;
   - изображения вставлены в текст на свои места;
   - без ручного форматирования, цветного текста, таблиц, отступов пробелами.
2. **Обложка `01_обложка.png`** — обязательна, ≥ **784 × 440** (готовится отдельно; можно собрать из ассетов игры).
3. **Скриншоты** — реальный геймплей с Android-устройства, до 10 шт., PNG/JPG, ≤ 5 МБ, без водяных знаков/логотипов чужих магазинов.
   Готовые кадры лежат в [`../rustore/screenshots/`](../rustore/screenshots/) (9 шт., 1920 × 1080):
   `01_gameplay_grass`, `02_gameplay_castle`, `03_gameplay_ice`, `04_gameplay_desert`,
   `05_gameplay_volcano`, `06_gameplay_kitchen`, `07_menu`, `08_settings`, `09_loading`.

## Как отправить (через RuStore Консоль)

1. Войти в [RuStore Консоль](https://www.rustore.ru/developer) → Хелп-центр → **«Предложить статью»**.
2. Прикрепить `.docx` и загрузить изображения отдельными файлами.
3. В **«Сообщение»** указать формат (**обзор**) и ссылку на карточку приложения в каталоге.
4. Поставить галочку согласия с Правилами и отправить. Срок рассмотрения — до 10 рабочих дней.

## Требования-памятка (кратко)

- Уникальность текста **≥ 90%** (проверка: text.ru / advego.com).
- Ссылки — только на `rustore.ru`; никаких «скачайте прямо сейчас», негативных сравнений, упоминаний других магазинов.
- Есть минимум 3 смысловых раздела с подзаголовками и блок **FAQ** из 5–10 вопросов.
- Тайтл ≤ 70 знаков (не дублирует название статьи), дескрипшен ≤ 170 знаков (не дублирует вводную часть).

## Правила проекта

Публикация и любые действия, меняющие состояние в RuStore, — **только с явного подтверждения пользователя** (правило 10 [`AGENTS.md`](../../AGENTS.md)).
