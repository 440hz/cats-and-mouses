# План: публикация CATS AND MOUSES в RuStore

Составлен 2026-09-30. **Обновлено 2026-10-11:** первой версией публикуется **1.2.0**
(локализация RU/EN выполнена — этап 120); `versionCode 102000`. **Статус: не публикуем —
будут ещё правки** (ждём отдельного подтверждения). Связанные документы: `PLAN.md`, `GAME.md`,
навык `.opencode/skills/rustore-publish/SKILL.md`.

## Исходное состояние

- Приложение `com.catsandmouses`, appStatus **NOT_PUBLISHED** (ни разу не публиковалось).
- В RuStore единственная версия **1.0.49** (versionCode 49, versionId `2064833696`),
  `READY_FOR_PUBLICATION`, MANUAL. Иконка + 6 скриншотов загружены в неё.
- Локально: `Constants.VERSION = 1.2.0`, android versionCode **102000** / versionName 1.2.0.
- Локализация RU/EN выполнена (этап 120); EN-листинг черновик — `store/common/listing.en.json`.
- APK (22.09) и AAB (21.09) устарели → нужна пересборка.
- `store/rustore/version.json` описывает 31 уровень / 6 миров и whatsNew от 1.0.49 → устарело
  (сейчас **41 уровень / 8 миров**, добавлены миры «Вулкан» и «Гигантская кухня», музыка/звук,
  экран «Настройки», локализация RU/EN). Обновлён под 1.2.0.

## Решения

1. Публикуем **только 1.1.1** (1.0.49 не публикуем → в архив).
2. Формат — **APK**.
3. Публикация — **вручную в Консоли RuStore**.
4. Черновик 1.0.49 → **архив**.
5. Тексты пишу я; **«Что нового» — расширенное**.
6. `version.json` (whatsNew, fullDescription, FAQ) — **правлю в репозитории**.
7. Скриншоты — **новые, заменяем** текущие 6.
8. Локализация **не делается**: RuStore русскоязычный, игра уже на русском.

## Роли

- **Агент:** тексты в `version.json`, пересборка APK, обработка скриншотов, обновление доков.
- **Пользователь:** съёмка скриншотов, публикация в Консоли.

## Шаг 1. Тексты — правка `store/rustore/version.json`

- **`whatsNew`:**

  ```
  Новое в версии 1.2.0:
  - английская локализация (переключатель языка в «Настройках»);
  - новый мир «Вулкан» — 5 карт с раскалённой лавой;
  - новый мир «Гигантская кухня» — ещё 5 карт;
  - всего в игре стало 41 уровень;
  - добавлены музыка и звуки;
  - новый экран «Настройки» с ползунками громкости музыки и звуков.
  Соберите весь сыр в восьми мирах и на финальной карте!
  ```

- **`fullDescription`:** `31 уровень в шести мирах: … затерянное болото;` →
  `41 уровень в восьми мирах: … затерянное болото, вулкан, гигантская кухня;`;
  в «Особенности» добавить `- музыка и звуки, экран «Настройки» с ползунками громкости;`.
- **FAQ** «Сколько в игре уровней?» →
  `41 уровень: восемь миров по пять карт и финальная карта. У каждого мира своё оформление.`

## Шаг 2. Пересборка APK (неблокирующе)

- `pwsh tools/build-bg.ps1 android:assembleRelease`
- Проверить: versionCode **101**, versionName **1.1.1**, `BUILD SUCCESSFUL`,
  подпись тем же ключом `android/catsandmouses-release.jks`.

## Шаг 3. Скриншоты — снимает пользователь, обрабатывает агент

- **Что снять** (≥5, клиентская область окна, без рамки/тайтлбара, без оверлея паузы
  и без отсчёта «3-2-1»):
  1. заставка/загрузка;
  2. главное меню;
  3. «Настройки»;
  4. геймплей мир 1 (grass);
  5. геймплей мир 7 «Вулкан»;
  6. геймплей финала.
- **Куда:** исходники — `store/rustore/screenshots/raw/` (или указанный путь).
- **Обработка (агент):** обрезка до клиентской области → апскейл LANCZOS до **1920×1080**
  (16:9) → JPG → замена `store/rustore/screenshots/NN_*.jpg`
  (первый кадр — самый сильный).
- `store/rustore/screenshots/` вне git — коммит не затрагивается.

## Шаг 4. Действия пользователя в Консоли RuStore

1. Версия **1.0.49** → **Архивировать**.
2. **Загрузить версию**: Универсальный / Игра →
   `android/build/outputs/apk/release/android-release.apk`.
3. Поля из шага 1, версия **1.1.1 / 101**.
4. Медиа: `store/rustore/icon_512.png` + новые скриншоты.
5. Режим публикации — **ручной** → **на модерацию** → после одобрения **Опубликовать**.

## Шаг 5. После публикации (агент)

- Обновить `GAME.md`, `PLAN.md`, `CHANGELOG.md`.
- Коммит — только по отдельному подтверждению (навык `git-workflow`).

## Ограничения

- Любые мутирующие действия в RuStore (`archive`, `draft-delete`, `release`, `publish`,
  `icon`, `screens`, `reply`, Gradle `rustoreRelease`) — **только после явного одобрения**
  (правило 10 `AGENTS.md`).
