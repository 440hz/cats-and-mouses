# CATS AND MOUSES

2D-игра в стиле **Pac-Man** с инверсией ролей. Игрок управляет **мышью**, а **три кота** охотятся за ней. Цель — собрать все точки в лабиринте, не попавшись котам.

![Статус сборки](https://img.shields.io/badge/build-passing-brightgreen) ![Платформы](https://img.shields.io/badge/platforms-Android%20%7C%20Desktop-blue) ![Kotlin](https://img.shields.io/badge/Kotlin-1.9.24-orange) ![LibGDX](https://img.shields.io/badge/LibGDX-1.12.1-purple)

## ⚙️ Технический стек

- **Язык**: Kotlin 1.9.24
- **Движок**: LibGDX 1.12.1
- **Платформы**: Android (minSdk 24, targetSdk 35) + Desktop (LWJGL3)
- **Сборка**: Gradle 8.9, Kotlin DSL, JDK 21

## 🕹️ Как играть

- **Мышь** двигается строго по сетке, поворот — только в центре клетки.
- **Цель** — съесть все точки на лабиринте (каждая даёт +10 очков).
- **Задача** — уворачиваться от трёх котов с разными стратегиями:

| Кот | Стратегия |
|-----|-----------|
| **Chaser** | На перекрёстке идёт к мыши кратчайшим путём (BFS) |
| **Patrol** | Ходит по периметру; атакует, если мышь рядом |
| **Random** | Блуждает случайно, с шансом 30% — за мышью |

### Управление (Desktop)

| Действие | Клавиши |
|----------|---------|
| Вверх / вниз | `W` / `S` или стрелки |
| Влево / вправо | `A` / `D` или стрелки |

Тач-управление для Android в разработке.

## 🚀 Запуск

### Desktop
```powershell
.\gradlew lwjgl3:run
```

### Android
```powershell
.\gradlew android:installDebug
```
Требуется подключённое устройство или эмулятор.

### Полная сборка
```powershell
.\gradlew build
```

> При ошибке кэша Gradle (`Could not read workspace metadata`) — удали содержимое `%USERPROFILE%\.gradle\caches\8.9\transforms` и собери с `.\gradlew build --no-daemon`.

## 📁 Структура

```
core/        Основная игровая логика (MainGame.kt, GameScreen.kt, MazeLoader.kt, entities/)
android/     Android-модуль
lwjgl3/      Desktop-модуль
assets/      Ресурсы (maze.txt — карта лабиринта)
```

## 🗺️ Изменение карты

Карта лабиринта — файл `assets/maze.txt`: **28 колонок × 16 строк**.

| Символ | Значение |
|--------|----------|
| `#` | стена |
| `.` | точка (+10 очков) |
| пробел | проход |
